# Contribuir

Usa os passos de [desenvolvimento e testes](README.md#desenvolvimento-e-testes) para preparar uma cópia local do projeto.

1. Descreve o problema e o resultado esperado numa issue ou na descrição do pull request.
2. Faz a alteração numa branch do teu fork.
3. Corre a suite. Se mudares o Docker Compose, verifica também o percurso de arranque do README.
4. Abre o pull request com um resumo e os resultados dos testes.

| Alteração | Onde começar |
| --- | --- |
| Calculadora, conversões ou API | [main.py](main.py) |
| Respostas por tema | [knowledge.py](knowledge.py) |
| Interface web | [templates/index.html](templates/index.html) |
| Testes | [tests/](tests/) |

Para propor uma resposta factual, indica uma fonte que permita confirmá-la. Usa dados fictícios e exemplos sem credenciais ao enviar resultados. Para problemas de segurança, segue a [política de segurança](SECURITY.md).
